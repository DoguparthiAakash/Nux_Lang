# Nux Programming Language (Windows)

Welcome to the Nux Programming Language distribution for Windows!

## What is Nux?

Nux is an incredibly fast, lightweight, and extensible programming language. It is designed to run everywhere while remaining powerful enough for advanced ML, 3D engines, Quantum computing interfaces, and OS-level interactions.

## Contents

- **nux-setup.exe**: The Windows Installer (NSIS-based).
- **install.ps1**: PowerShell automated installer.
- **update.ps1**: Update manager for Windows.
- **uninstall.ps1**: Completely cleans Nux from your system.
- **nux_source_only.zip**: The standard library and source code for manual installs.

## Quick Start

Check `SetupGuide.md` for installation instructions and `UserGuide.md` on how to start writing your first Nux program!
