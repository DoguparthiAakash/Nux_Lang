# Nux Setup Guide (Windows)

This guide explains how to install and update Nux on Windows.

## Installation

1. Run `nux-setup.exe` and follow the prompts.
2. Alternatively, right-click `install.ps1` and select 'Run with PowerShell'.
3. The installer will extract files and add `nux` to your System PATH.

## Updating Nux

Run the included update script to fetch the latest versions without reinstalling manually.
```powershell
.\update.ps1
```

## Uninstallation

If you need to remove Nux:
```powershell
.\uninstall.ps1
```
Or use the Windows 'Add or Remove Programs' menu.
